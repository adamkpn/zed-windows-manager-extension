# Zed Windows Changelog

## [1.0.0] - 2026-11-03

- **Search Zed Windows**: list the open Zed windows, most recently used first, with path and git branch. Search by folder, path or branch, then ↵ to focus the window.
- **Zed Open.app** (`make droplet`): an "Open with" app for launchers such as Git Repos. It focuses the Zed window that already has the folder open; otherwise it runs `git pull --ff-only` and opens a new window.
